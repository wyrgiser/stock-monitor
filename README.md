# 买点雷达

公开的 A 股 / 港股实时买点监控看板。

## 功能

- 完整展示 337 只观察股票
- 浏览器每 60 秒从腾讯行情接口刷新现价与日涨跌
- 每日从东方财富公开财务数据更新 A 股 ROE 和上一财年股息率
- 按目标买入价计算距买点百分比
- 市场、仓位、分类、关键词筛选
- 自定义标的保存在浏览器本地
- CSV 导出
- GitHub Pages 自动部署

## 部署

仓库 Settings → Pages → Source 选择 **GitHub Actions**。推送到 `main` 后工作流会自动发布。

> 数据仅供学习和观察，不构成投资建议。
